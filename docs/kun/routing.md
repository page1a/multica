# 路由交格子协议

路由只接管有下游消费者的格子；填法必须确定或可验证，优先继承父票或来源，无法确定就留空；所有写入继续遵守只填空格、条件写入、一次决策一条评论，人手填写永远不覆盖。

当前交给路由的格子：

- 存量 `todo`：每轮每工作区最多 25 张，选择 quiet 超过 30 分钟且执行席或验收席为空的票，调用同一个 `Route`。只扫 `todo`；`backlog`、`blocked` 和人持有的票不碰。`Route` 幂等，所以重复扫描安全。
- 所属项目：子票没显式项目时继承父票；智能体运行中建票没填项目时，继承该运行所属的票或聊天的项目。聊天绑定多个项目时留空，不猜。
- 优先级：子票优先级为 `none` 时继承父票；手填优先级不覆盖。顶层票不由模型猜优先级。

标签没有消费者，截止日期是人的承诺，状态由服务端送审/合入门禁负责；这些格子不交给路由。路由顶部注释和 `server/internal/routing/` 的状态表保持同一边界。
